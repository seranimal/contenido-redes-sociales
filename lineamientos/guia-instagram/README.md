# Guía de Instagram · Ser Animal

Página con todo lo que hace falta para publicar:

- el perfil ideal: bio, destacadas y grilla;
- las reglas de oro;
- los pilares, con carruseles de ejemplo;
- las portadas animadas;
- las historias;
- el ritmo semanal;
- el paso a paso para armar un post, con la plantilla del texto del posteo;
- los brand assets y la lista de control antes de publicar.

Publicada en: https://claude.ai/artifact/5AePxi5nkGih1FLisRUfgb

**Fuente:** `index.html` + `img/`. Para actualizarla, editar `index.html` y volver a publicarla.

**De dónde salen los ejemplos**

- Son los posts reales del lote de noviembre y diciembre (`posts/2026-11-*` y `posts/2026-12-*`), armados con las plantillas de Ser Animal Studio.
- Las fotos son de Unsplash (licencia libre). Los créditos de cada una están en el `texto.md` de su post.
- Las fotos de producto se hicieron con Nano Banana Pro a partir de las fotos de seranimal.com.uy.
