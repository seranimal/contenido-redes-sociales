# Fuente

Se arma con Ser Animal Studio (plantillas «Foto · título editorial arriba» y «Producto · ficha con info»).

- `proyecto.cjs`: el proyecto del Studio (textos, encuadre y fotos).
- `assets/husky.jpg`: foto de la portada (de seranimal.com.uy, producto «Conjunto Correa + Pechera para Perro»).
- `assets/husky-sujeto.png`: recorte del perro (rembg, modelo isnet-general-use), por si se quiere la versión con profundidad.
- `assets/conj-familia.jpg`: los tres colores del producto (fotos de la web recortadas con rembg y superpuestas) sobre blanco, para la ficha.

Para volver a exportar: cargar el proyecto en el Studio (o con el script de render de la guía) y descargar el ZIP.
