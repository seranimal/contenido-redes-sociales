# Fuente

Se arma con Ser Animal Studio (plantillas «Portada · título con profundidad» y «Producto · ficha con info»).

- `proyecto.cjs`: el proyecto del Studio (textos, encuadre y fotos).
- `assets/husky.jpg`: foto de la portada (de seranimal.com.uy, producto «Conjunto Correa + Pechera para Perro»).
- `assets/husky-sujeto.png`: recorte del perro, mismo tamaño que la foto, para que el título pase por detrás. Hecho con rembg (modelo isnet-general-use).
- `assets/beagle-blanco.jpg`: foto de la web recortada y puesta sobre blanco para la ficha.

Para volver a exportar: cargar el proyecto en el Studio (o con el script de render de la guía) y descargar el ZIP.
